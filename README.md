## ✨ 遊戲特色

1. **16 色幾何切面向量插畫 & 原畫比例不裁切**
   - 採用雙邊濾波、色度加權 16 色量化、多階段碎塊整併與拓樸直線多邊形向量化（Topological Straight-Line Polygon Vectorizer），完整保留原畫長寬比例。
2. **相近色系連續排列調色盤 + 點擊原畫吸色**
   - 16 色調色盤依色度加權 CIELAB 最短感知路徑排序，同色系按明度連續排列。
   - **💧 點擊原畫吸色**：直接點擊左側原畫參考任意區域，即可自動吸取並切換至對應色票。
3. **1 至 5 星色塊碎裂度難度標示（`★☆☆☆☆` ～ `★★★★★`）**
   - 依據每幅名畫幾何色塊數量標示 1～5 顆星難度與色塊數。
4. **博物館導覽牌與高清原畫對照**
   - 畫室下方附有作品中文簡介，並可隨時點擊「🖼 查看原畫」對照博物館館藏原圖；結算時支援並排、滑桿、差異熱區與疊影對照，並可匯出紀念明信片。
